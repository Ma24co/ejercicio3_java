# ejercicio3_java
ejercicio 3 java
Desarrolle un programa en Java que genere una secuencia de números enteros al azar comprendidos entre 0 y 10.

Cada vez que se genere un número, el programa deberá mostrarlo en pantalla e indicar mediante un mensaje si el valor es par o impar.

Cuando el número generado sea impar, deberá sumarse a una variable acumuladora. El proceso continuará mientras la suma de los números impares sea menor o igual que 25.

El programa deberá detener la generación de números inmediatamente después de que la suma de los valores impares supere 25. Al finalizar, deberá mostrar en pantalla la suma total calculada.
